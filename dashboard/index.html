How the value is computed

implied value = TVL × peer multiple × growth × maturity

  • Peer multiple. The median market-cap-to-TVL ratio of the protocols in the same category whose token already trades, shrunk toward the all-category median when peers are few — so a category with one loud peer cannot set the price on its own.
  • Growth. From the protocol's seven-day TVL change, clamped to −50%…+150% and weighted one half.
  • Maturity. From how long the protocol has run: 0.70 at listing, rising to 1.00 after two years with no token recorded.

A protocol records no token — the snapshot is DefiLlama's record, not proof, and a listed protocol may still have a token its record does not carry. Implied values are this entry's model, not a promise and not a prediction that a token will be issued. No protocol name is special-cased: the same arithmetic scores every row, and this page recomputes every number it shows.
